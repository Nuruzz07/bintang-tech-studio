# apps/seller-dashboard

Authenticated merchant management portal for Bintang Tech Studio.

## Role & Boundary

- Allows store owners and staff to manage products, categories, vouchers, inventory credentials, and view sales metrics.
- Enforces user authentication and store membership authorization before granting access.
- Planned deployment: Vercel.

## Implementation Status

- **M01 Status:** Structural placeholder.
- **Planned Milestone:** M12 (Seller Dashboard).
- Replaces legacy client-side admin simulations with full authenticated application.
- No frontend framework is initialized during M01.
